# Changelog

All notable changes to this project will be documented here.

## 0.1.0 - 2026-06-01

### Added

- Initial IoT campus map demo.
- Simulated unit data for National Tsing Hua University.
- Unit map, unit plan, indoor floor plan, and outdoor place views.
- Irregular place footprints based on building-like outlines.
- Floor switching rail for indoor places.
- Mock device data for cameras, lights, and access control.
- Green and red status indicators for normal and abnormal devices.
- Pan, wheel zoom, zoom buttons, and reset view controls.
- 4K-friendly floor plan fitting behavior.
- Project documentation, roadmap, changelog, contribution guide, screenshot, and GitHub Pages publishing notes.
