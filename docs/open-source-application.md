## Maintainer Role

Primary maintainer.

## Why this repository qualifies

This is an open-source IoT campus and facility map demo that shows multi-level navigation from a campus map to place plans and indoor floor plans. It demonstrates device status visualization for cameras, lights, and access control, using a mock API JSON structure that other developers can adapt for smart campus, park operations, building management, and safety monitoring interfaces. The project is early-stage but intended to become a reusable reference for frontend developers building IoT map and floor-plan experiences.

## How API credits would be used

API credits would be used to improve the open-source project by generating richer mock datasets, reviewing frontend code quality, creating additional documentation, producing release notes, drafting issue triage responses, and helping design reusable components for map navigation, floor switching, device filtering, and alert workflows. The goal is to make the project easier for other developers to understand, reuse, and extend.

## Additional context

The repository currently includes a working static demo, mock API data, a floor plan asset, documentation, roadmap, changelog, contribution guide, and GitHub Pages deployment workflow. Future work will focus on accessibility, filtering, URL state, multiple campuses, real map provider integration, and more realistic uploaded floor plan examples.
