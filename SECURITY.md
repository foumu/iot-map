# Security Policy

## Supported Versions

This is an early-stage static demo. Security updates apply to the latest commit on `main`.

## Reporting a Vulnerability

Please open a private report if GitHub private vulnerability reporting is enabled. If it is not enabled, create an issue with a high-level description and avoid posting sensitive exploit details publicly.

Useful information to include:

- affected file or feature
- reproduction steps
- expected and actual behavior
- browser and operating system

## Current Security Scope

The project currently has no backend service, database, authentication, or secret storage. Most security work is expected to focus on safe frontend behavior, dependency choices if dependencies are added later, and avoiding unsafe handling of uploaded floor-plan assets in future versions.
