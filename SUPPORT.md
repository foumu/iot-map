# Support

For questions, bugs, and feature ideas, please use GitHub Issues.

## Good Issue Topics

- Demo does not load locally
- JSON data shape is unclear
- Device markers render in the wrong position
- Floor plan scaling or panning behaves unexpectedly
- Accessibility improvements
- Ideas for smart campus or IoT dashboard workflows

## Before Opening an Issue

- Try the latest `main` branch.
- Confirm `data/iot-map.json` is valid JSON if you changed mock data.
- Include browser, operating system, screen size, and reproduction steps.
