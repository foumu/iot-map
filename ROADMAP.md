# Roadmap

This roadmap focuses on turning the demo into a more reusable open-source reference for IoT map interfaces.

## Near Term

- Add URL state so a specific place or floor can be linked directly.
- Add search and filters for device type, status, and place.
- Add keyboard-accessible navigation for map markers and floor buttons.
- Add more realistic uploaded floor plan examples.
- Add screenshots for unit plan, outdoor place, and indoor floor views.

## Mid Term

- Extract rendering logic into reusable modules.
- Add a small mock API server option for developers who want endpoint-style integration.
- Add device clustering for dense floor plans.
- Add alert and maintenance event samples.
- Add unit tests for data helpers and status aggregation.

## Long Term

- Support real map providers behind a configuration layer.
- Support drawing and editing place footprints from backend data.
- Support multiple campuses and cross-campus navigation.
- Provide design tokens and reusable UI components for IoT dashboards.
- Publish a hosted demo with versioned releases.
